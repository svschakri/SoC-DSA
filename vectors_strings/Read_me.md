# Vectors

A **vector** is a dynamic array — it can grow or shrink in size during runtime, unlike a normal (static) array whose size is fixed at creation.

## vector terminology

There are a bunch of things you have to know about vectors like size, capacity, resizing, iterators, and 2D vectors.

### size vs capacity

**Size** is the number of elements currently stored in the vector. **Capacity** is the amount of memory currently allocated, which may be larger than size to allow room for growth without reallocating every time.

### Example

#### input

push_back(1), push_back(2), push_back(3)

#### output

size = 3, capacity >= 3 (implementation dependent, often capacity grows in powers of 2)

### push_back / pop_back

**push_back** adds an element to the end of the vector. **pop_back** removes the last element. Both run in amortized O(1) time.

### Example

#### input

[1,2,3] -> push_back(4)

#### output

[1,2,3,4]

#### input

[1,2,3,4] -> pop_back()

#### output

[1,2,3]

### insert / erase

**insert** places an element at a given position, shifting later elements right. **erase** removes an element at a given position, shifting later elements left. Both run in O(n) time since they may shift many elements.

### Example

#### input

[1,2,4], insert(index=2, value=3)

#### output

[1,2,3,4]

#### input

[1,2,3,4], erase(index=1)

#### output

[1,3,4]

### resizing

When a vector's capacity is exceeded, it **reallocates**: a new, larger block of memory is allocated (commonly double the old capacity), all existing elements are copied over, and the old block is freed. This is why push_back is only *amortized* O(1) rather than strictly O(1) — most calls are cheap, but occasional resizes cost O(n).

### iterators

A vector exposes **begin()** and **end()** iterators that let you traverse elements sequentially, similar to pointers. This allows vectors to work with generic algorithms like sort, reverse, and find.

### Example

#### input

[3,1,2], sort(begin, end)

#### output

[1,2,3]

### 2D vectors (vector of vectors)

A vector can store other vectors as elements, forming a **2D vector** — useful for representing grids, matrices, or adjacency lists in graphs.

### Example

#### input

vector<vector<int>> grid = {{1,2},{3,4}}

#### output

grid[0] = [1,2], grid[1] = [3,4]

### front / back

**front()** returns the first element, **back()** returns the last element, both in O(1) time without removing them.

### Example

#### input

[5,6,7]

#### output

front = 5, back = 7

### sort

**sort** rearranges the elements of a vector into a given order (ascending by default) using the begin() and end() iterators. It typically runs in O(n log n) time. A custom comparator can be passed to sort in descending order or by a custom rule.

### Example

#### input

[4,1,3,2], sort(begin, end)

#### output

[1,2,3,4]

#### input

[4,1,3,2], sort(begin, end, greater<int>())

#### output

[4,3,2,1]

### accumulate

**accumulate** sums up (or combines, with a custom operation) all elements in a range, given a starting value. It runs in O(n) time. By default it computes the sum, but a custom binary operation (like multiplication) can be passed instead.

### Example

#### input

[1,2,3,4], accumulate(begin, end, 0)

#### output

10

#### input

[1,2,3,4], accumulate(begin, end, 1, multiplies<int>())

#### output

24

The common use cases for vectors include dynamic sizing when the number of elements is unknown ahead of time, building adjacency lists for graphs, and serving as the backbone for other structures like stacks and queues.

# Strings

A string basically is array of charachters

## string terminology

There are bunch of stuff you have to know about strings like substring,subsequence,prefix,suffix,rotation,etc.

### substring

A **substring** is sequence of consecutive characters in a string.We use notations s[a..b] to refer a substring starts at position a and ends at position b.A string of length n has n(n+1)/2 substrings.

### Example 

#### input

ABCD

#### output

A,B,C,D,AB,BC,CD,ABC,BCD,ABCD.

### subsequence

A subsequence is sequence of (not necessarily consecutive) characters in a string in their original order.A string of length n has 2<sup>n</sup> -1 subsequence.

### Example 

#### input

ABCD

#### output

A,B,C,D,AB,AC,AD,BC,BD,CD,ABC,ABD,ACD,BCD,ABCD.

### prefix 

A **prefix** is a substring that starts at the beginning of the string.


### Example 

#### input

ABCD

#### output

A,AB,ABC,ABCD.

### suffix 

A **suffix** is a substring that ends at the end of the string.


### Example 

#### input

ABCD

#### output

D,CD,BCD,ABCD.


### rotation

A **rotation** can be generated by by moving the characters of string one by one from the begging to the end
(or vice-versa)

### Example 

#### input

ABCD

#### output

ABCD,BCDA,CDAB,DABC.

### period

A **period** is a prefix of a string such that the string can be constructued by repeting the period.The last repetition may be partial and contain only a prefix of the period

### Example 

#### input

ABACABA.

#### output

ABAC.

### border

A **border** is a string that is both prefix and suffix of a string.

### Example 

#### input

ABACABA.

#### output

A,ABA.

## Trie

A **Trie** (prefix tree) stores a set of strings so that every node represents a prefix. Each node has up to 26 children (for lowercase letters) and a flag marking whether a word ends there. Insert and search both run in O(L) time, where L is the length of the string.

```cpp
struct TrieNode {
    TrieNode* children[26] = {};
    bool isEnd = false;
};

TrieNode* root = new TrieNode();

void insert(string& word) {
    TrieNode* node = root;
    for (char c : word) {
        int idx = c - 'a';
        if (!node->children[idx])
            node->children[idx] = new TrieNode();
        node = node->children[idx];
    }
    node->isEnd = true;
}

bool search(string& word) {
    TrieNode* node = root;
    for (char c : word) {
        int idx = c - 'a';
        if (!node->children[idx]) return false;
        node = node->children[idx];
    }
    return node->isEnd;
}
```

## string hashing

**String hashing** maps a string to a number so two strings can be compared for equality in O(1) (after O(n) preprocessing), and any substring's hash can be computed in O(1) using prefix hashes. A common scheme is polynomial hashing with a base and a modulus.

```cpp
const int MOD = 1e9 + 7;
const int BASE = 31;

vector<long long> prefixHash, powBase;

void buildHash(string& s) {
    int n = s.size();
    prefixHash.assign(n + 1, 0);
    powBase.assign(n + 1, 1);
    for (int i = 0; i < n; i++) {
        prefixHash[i + 1] = (prefixHash[i] * BASE + (s[i] - 'a' + 1)) % MOD;
        powBase[i + 1] = (powBase[i] * BASE) % MOD;
    }
}

// hash of substring s[l..r] (0-indexed, inclusive)
long long getHash(int l, int r) {
    long long hash = (prefixHash[r + 1] - prefixHash[l] * powBase[r - l + 1]) % MOD;
    if (hash < 0) hash += MOD;
    return hash;
}
```

## Z-algorithm

The **Z-algorithm** builds a Z-array where z[i] is the length of the longest substring starting at i that matches a prefix of the string. It runs in O(n) using a window [l, r] representing the rightmost match found so far.

```cpp
vector<int> zFunction(string& s) {
    int n = s.size();
    vector<int> z(n, 0);
    int l = 0, r = 0;
    for (int i = 1; i < n; i++) {
        if (i < r)
            z[i] = min(r - i, z[i - l]);
        while (i + z[i] < n && s[z[i]] == s[i + z[i]])
            z[i]++;
        if (i + z[i] > r) {
            l = i;
            r = i + z[i];
        }
    }
    return z;
}
```
